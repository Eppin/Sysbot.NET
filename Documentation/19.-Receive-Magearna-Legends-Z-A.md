# Legends: Z-A: Receive Magearna

This guide covers receiving Magearna until a `StopCondition` is met (e.g., specific IVs, etc.).

## Prerequisites

- Have access to the Magearna event/interactions

## Setup

1. Stand directly in front of the interaction that gives Magearna
2. Make sure slot 1 of box 1 (B1S1) is empty
3. **Save your game**
4. Start the bot

## How It Works

The bot will:
1. Repeatedly advance dialogue/interactions to receive Magearna
2. Check B1S1 for the received Magearna
3. Validate Magearna against your stop conditions
4. If no match is found, reset and repeat the process

Since Magearna is available in B1S1 before the auto-save is triggered, this routine can run without any cheats needed.

## Tips

- Make sure you are positioned correctly before starting
- Keep B1S1 empty to avoid species mismatch errors
- Use stop conditions to target specific Magearna (shiny, nature, IVs, etc.)
