# Legends: Z-A: Receive Hoopa

This guide covers receiving Hoopa until a `StopCondition` is met (e.g., specific IVs, etc.).

## Prerequisites

- Have access to the Hoopa event/interactions

## Setup

1. Stand directly in front of the interaction that gives Hoopa
2. Make sure slot 1 of box 1 (B1S1) is empty
3. **Save your game**
4. Start the bot

## How It Works

The bot will:
1. Repeatedly advance dialogue/interactions to receive Hoopa
2. Check B1S1 for the received Hoopa
3. Validate Hoopa against your stop conditions
4. If no match is found, reset and repeat the process

Since Hoopa is available in B1S1 before the auto-save is triggered, this routine can run without any cheats needed.

## Tips

- Make sure you are positioned correctly before starting
- Keep B1S1 empty to avoid species mismatch errors
- Use stop conditions to target specific Hoopa (shiny, nature, IVs, etc.)
